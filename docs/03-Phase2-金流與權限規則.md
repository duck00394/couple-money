# Phase 2 金流與權限規則（2026-09-17 確認版）

## 四種錢

| 概念 | 意思 | 從哪裡算 |
|---|---|---|
| 個人／共同帳戶「實際餘額」 | 錢真的在哪裡 | Transaction（支出、收入、結算、轉帳…） |
| 帳戶「已指定給基金」 | 帳戶裡被指定用途的錢 | FundTransaction（同一個 accountId） |
| 帳戶「可自由使用」 | 實際餘額 − 已指定給基金 | 計算 |
| 基金「實際金額」 | 投入 − 取回 − 基金支出 + 獎金入金 | FundTransaction |
| 基金「尚未入金獎金」 | 任務獎金 − 懲罰（尚未結算），不是現金 | TaskReward − TaskPenalty |

## 規則

1. **基金支出**：付款帳戶照常扣款（只扣一次）、基金實際金額減少、分帳照常產生欠款。
   基金支出會動用某個帳戶裡「指定給基金」的額度（預設優先付款帳戶，否則額度最多的帳戶，也可以手動選）。
   基金實際金額不夠、或單一帳戶額度不夠時整筆消費不會建立。
2. **任務獎金**：完成任務只建立 TaskReward（已獲得、尚未入金），不動任何帳戶。
   基金頁「入金」一次結算該基金所有尚未入金的獎金與懲罰：
   - 選「從某帳戶轉入」→ 建立帳戶間轉帳（來源 −、入金帳戶 +）
   - 選「錢已經在入金帳戶裡」→ 只指定用途
   之後建立 REWARD_DEPOSIT（基金實際金額 +），獎金／懲罰標記為已結算。可以取消入金（紀錄保留、作廢）。
   已入金的打卡不能取消、已抵扣的懲罰不能免除（要先取消入金）。
3. **投入基金不得超過帳戶可自由使用金額**；取回只能從該帳戶的額度取回；取消取回若會讓可自由使用變負數會被擋。
   尚未入金獎金可以存在，但不算現金、不能拿來付基金支出。
4. **權限**
   - 任務名稱、說明、需要照片、需要確認、停用：雙方可改
   - 任務獎金、懲罰、週期、獎金基金、里程碑：只有建立者可改
   - 執行者建立後不可更換；刪除任務只有建立者
   - 停用不能規避懲罰：停用前先結算到昨天的懲罰；執行者在「今天要做、還沒完成」時停用，今天照樣記一次懲罰
   - 共同目標：雙方可編輯；刪除需要另一半同意
   - 共同基金：雙方可投入、取回、支出、入金；刪除需要另一半同意（且實際金額為 0、沒有尚未入金獎金、沒有任務使用）
