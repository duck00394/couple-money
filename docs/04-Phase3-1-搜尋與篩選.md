# Phase 3-1 搜尋與篩選

## 可用條件（網址參數，重新整理或分享都保留）

| 條件 | 參數 | 說明 |
|---|---|---|
| 關鍵字 | `q` | 名稱、備註、商家、分類名稱、標籤、帳戶名稱 |
| 日期區間 | `from`、`to` | 帳本時區（台灣時間），含頭含尾；顛倒自動對調 |
| 類型 | `kind` | 支出、收入、退款、帳戶間轉帳、結算、基金支出、任務獎金入金、期初餘額 |
| 分類 | `category` | |
| 付款／收款人 | `person` | 我、另一半、共同帳戶（任一金流行屬於這個人） |
| 帳戶 | `account` | 任一金流行使用這個帳戶 |
| 基金 | `fund` | 連結到該基金的基金支出，以及該基金的任務獎金入金轉帳 |
| 標籤 | `tag` | 記帳時新增的標籤 |
| 金額區間 | `min`、`max` | 以元輸入；顛倒自動對調 |

專案：目前資料庫還沒有專案資料表，所以沒有這個條件。

## 結果統計規則

- 實際淨支出 = 支出 − 退款
- 收入只算「收入」類型
- 帳戶間轉帳（含任務獎金入金）另外列出，不算收入或支出
- 結算、期初餘額不算收支
- 基金投入（指定用途）不是交易，不會出現在記帳搜尋結果
- 尚未入金的任務獎金不是交易，不會出現

## 權限

所有查詢都限制在目前帳本；用別的帳本的帳戶、基金、分類 id 篩選只會查不到。
